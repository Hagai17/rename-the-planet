Entry for the make.fun competition
[Rename the Planet](https://make.fun/c/u-motasimfuad-rename-the-planet-094b0369):
one funny new name for a planet in our solar system, plus the why, in a single
line under 200 characters.

The entry:

> Rename Mars 'The Bad Neighbourhood': its only two moons are named Fear and Panic, and every rover we send there eventually stops answering.

Mars's only two moons really are Phobos and Deimos — Fear and Panic — and the
rovers really do stop answering. The name earns itself twice.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it.

`candidates.md` holds the drafts and the head-to-head duels that picked this line.
